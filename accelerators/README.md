# Catálogo de aceleradores

Soluciones Azure parametrizables, documentadas, validables y con versionado SemVer independiente. Una entrada en el catálogo no implica que el activo esté listo para producción.

| Acelerador | Versión objetivo | Estado | Alcance |
| --- | --- | --- | --- |
| [App Service + PostgreSQL](app-service-postgresql/README.md) | 0.1.0 | Diseño inicial, sin release | Aplicación pública y PostgreSQL Flexible Server privado. |

Cada acelerador debe incorporar infraestructura, parámetros de ejemplo, pipeline, aplicación de ejemplo y documentación de arquitectura y operación antes de considerarse terminado. La selección de servicios y tamaños depende del escenario; no se incluyen datos de clientes.
